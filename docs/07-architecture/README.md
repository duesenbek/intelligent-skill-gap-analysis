# CareerLens Architecture Diagrams

This folder contains the initial architecture diagrams for the CareerLens MVP.

## Files
- `system-context.md` — system context, actors, and external entities.
- `use-case.md` — core user scenarios and system responsibilities.
- `component-diagram.md` — proposed application components and dependencies.

## Rendering
Each file contains Mermaid source. GitHub can render Mermaid diagrams in Markdown. The source is intentionally kept editable.

## Scope assumptions
# CareerLens — Project Proposal (Architecture Assumptions)

This architecture package assumes CareerLens is a responsive web application that helps students and early-career professionals compare their self-reported skills with the requirements of a selected software-engineering role and receive prioritized, explainable learning recommendations.

**Scope boundary:** The initial MVP focuses on a small, curated set of software-engineering roles and structured skill data. Resume parsing, external job-board integrations, generative-AI features, and automated collection of personal data are out of scope unless the team explicitly approves and implements them.

**Status:** Draft architecture for review. Components are proposed, not claims of completed implementation. The team must align the diagrams with the final selected technology stack and implemented requirements.
