# CareerLens
## Intelligent Skill Gap Analysis and Personalized Career Recommendations

CareerLens is a diploma project focused on designing and developing a web-based system that helps students and early-career professionals identify skill gaps relative to a target career and create a personalized development roadmap.

### Official Diploma Project Title
**Design and Development of an Intelligent Skill Gap Analysis and Personalized Career Recommendation System**

---

## 1. Problem Statement

Students and early-career professionals may find it difficult to determine which skills they need to develop for a specific professional role. General career advice and lists of job requirements do not always provide a clear, personalized explanation of existing skill gaps or a practical order in which to address them.

CareerLens aims to investigate this problem and develop a system that compares a user's current skills with a defined target-role competency profile and presents actionable recommendations for further development.

The problem statement and proposed requirements will be refined using evidence gathered from potential users, relevant scientific publications, and an analysis of existing solutions.

---

## 2. Target Users

The initial target users are:

- University students preparing for their first professional role.
- Recent graduates entering the job market.
- Early-career professionals planning to improve their competencies or change career direction.

The initial prototype will focus on a limited set of professional roles selected during the requirements and feasibility analysis.

---

## 3. Project Aim

To design, implement, and evaluate a web-based system for identifying skill gaps and generating personalized career-development recommendations based on defined professional competency requirements.

---

## 4. Project Objectives

1. Investigate user needs and the relevance of the identified problem.
2. Review scientific literature and existing career-development and skill-assessment systems.
3. Compare alternative technologies and justify the selected technical approach.
4. Define functional and non-functional requirements and measurable acceptance criteria.
5. Design the system architecture and user experience.
6. Develop a prototype that compares user skills with target-role requirements.
7. Implement a method for identifying skill gaps and prioritizing development needs.
8. Generate a personalized skill-development roadmap.
9. Design and conduct tests to evaluate the system against a defined baseline.

---

## 5. Expected Outcomes

The expected project outcomes are:

- A documented and justified system architecture.
- A web-based prototype for skill gap analysis.
- A structured representation of professional skill requirements.
- A report identifying missing or underdeveloped skills.
- Personalized recommendations for skill development.
- An evaluation report describing the testing methodology, results, and limitations.

These are intended outcomes; their implementation and evaluation will be documented as development progresses.

---

## 6. Project Scope

### Planned MVP Features

- Selection of a target professional role.
- Input and assessment of the user's current skills.
- Comparison of user skills against a defined competency profile.
- Identification and prioritization of skill gaps.
- Generation of a personalized development roadmap.
- Presentation of results through a clear web interface.
- Testing of the analysis and recommendation process.

### Outside the Initial Scope

Unless the requirements analysis justifies otherwise, the initial MVP will not attempt to provide:

- Comprehensive coverage of every profession.
- Guaranteed employment or hiring predictions.
- Automatic integration with every job platform.
- A separately developed native mobile application.
- Claims of AI accuracy that have not been experimentally validated.

---

## 7. Technology Stack

The final technology stack will be selected after a documented comparison of alternatives.

The comparison will consider:

- Frontend framework.
- Backend platform and API design.
- Database technology.
- Skill gap analysis and recommendation methods.
- Testing, maintainability, security, and deployment requirements.

Specific technologies will be documented in the technology comparison and updated here after the team approves its architectural decisions.
