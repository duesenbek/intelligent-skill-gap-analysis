# Diagrams

This directory contains system architecture and design diagrams for CareerLens.

## Planned Diagrams

- **Context Diagram (C4 Level 1):** System boundary, user interactions, and external integrations.
- **Container Diagram (C4 Level 2):** High-level technical containers (frontend, API backend, database, ML/analysis module).
- **Component Diagram (C4 Level 3):** Internal component decomposition of core services (gap analysis, career recommender).
- **Workflow Diagrams:** User skill intake, resume parsing, and learning roadmap generation sequences.

## Directory Layout

- `src/` — Editable diagram source files (`.drawio`, `.puml`, etc.)
- `exports/` — Exported vector and bitmap images (`.svg`, `.png`) for inclusion in reports and markdown docs.
